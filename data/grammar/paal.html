Pa'al בִּנְיַן פָּעַל

Pa'al (also called קַל, "light") is the most common binyan and holds the most basic verbs: write, eat, go, sit, buy, close. If you learn one binyan properly, make it this one.

The shape

With the root כ־ת־ב (write):

  • Present: o–e → כּוֹתֵב (kotev)
  • Past: a–a → כָּתַב (katav)
  • Future: yi–o → יִכְתּוֹב (yichtov)
  • Infinitive: li–o → לִכְתּוֹב (lichtov)

The letters ב כ פ switch sound depending on position: kotev but yichtov, katav. Don't let that throw you — it's the same verb.

On the street: commands are just the future

The short textbook command (כְּתוֹב!) sounds bossy or like a sign. In conversation people use the future form: תִּכְתּוֹב לִי = write to me. Negative commands always use אַל + future: אַל תִּסְגּוֹר = don't close it. The drills accept both forms.

Infinitive: לִכְתּוֹב — used after wanting, needing, being able: אֲנִי צָרִיךְ לִכְתּוֹב לוֹ = I need to write to him.

You'll hear "אֲנִי יַגִּיד"

Many native speakers use the י-prefix for "I" in the future: אֲנִי יֵלֵךְ, אֲנִי יַגִּיד instead of אֵלֵךְ, אַגִּיד. It's extremely common, but it marks you as very casual (some people find it sloppy). Understand it; write the standard form.
